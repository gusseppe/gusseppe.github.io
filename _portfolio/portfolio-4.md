**Client:** SUNAT (Peruvian Tax Administration) - Inter-American Development Bank

End-to-end MLOps system enabling continuous delivery of ML models for tax evasion detection. Architected and deployed enterprise-grade infrastructure processing 1TB+ of financial data monthly.

**Technical Stack:**
- MLFlow for model management
- JupyterHub for collaborative development
- Minio for data storage
- PostgreSQL for metadata
- Ray for distributed computing
- Kubernetes for orchestration

**Impact:**
- $10M+ increase in tax revenue
- Processing 1TB+ financial data monthly
- 92% accuracy in fraud detection
- Real-time customs fraud pattern detection
